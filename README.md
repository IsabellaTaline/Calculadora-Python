# CALCULADORA-PYTHON
Aplicando conceitos básicos de programação em liguagem Python: Calculadora desktop, utilizando a biblioteca Tkinter.

Esse projeto foi desenvolvido com objetivo de aprendizado **nível iniciante**, servindo como uma introdução prática ao desenvolvimento de aplicações em linguagem Python. A aplicação realiza operações matemáticas básicas e demonstra conceitos fundamentais de programação orientada a eventos.

# Funcionalidades
* Operações aritméticas básicas: Adição (+), Subtração (-), Multiplicação (*), Divisão (/), Porcentagem (%)
* Suporte a números decimais
* Limpeza do visor
* Exibição dinâmica dos cálculos
* Interface gráfica intuitiva desenvolvida com `Tkinter`

# Tecnologia Utilizada
* Python 3

# Conceitos Aplicados
* Estruturas de funções
* Manipulação de variáveis globais
* Tratamento de eventos
* Construção de interfaces gráficas
* Utilização de widgets do Tkinter (Responsável pela interface gráfica)
* Organização de layouts com Frames
* Manipulação de texto com `StringVar()`
* Avaliação de expressões matemáticas com `eval()`

# Interface
A interface foi construída utilizando uma paleta de cores personalizada para proporcionar uma experiência visual simples, mas agradável, separando visualmente os números, operadores e ações principais, como uma calculadora desktop básica.

# Executando o Projeto
1. Certifique-se de ter Pyhton instalado na máquina
2. Copie o código
3. Execute utilizando um editor de código (Recomendo o **VS Code**)
